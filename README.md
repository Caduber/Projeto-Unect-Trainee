# Projeto Unect Trainee
Bem-vindo ao repositório do Projeto Unect Trainee, desenvolvido por Caduber. Este projeto foi criado como parte do processo seletivo para a vaga de trainee na empresa Unect.

# 📁 Estrutura do Projeto
O projeto é composto pelos seguintes diretórios e arquivos principais:

index.html: Página principal do projeto.

styles/: Contém os arquivos CSS responsáveis pela estilização da aplicação.

scripts/: Contém os arquivos JavaScript que adicionam interatividade à aplicação.

src/imgs/: Diretório contendo as imagens utilizadas no projeto.

# 🚀 Tecnologias Utilizadas
O projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML5: Estruturação do conteúdo da web.

CSS3: Estilização e layout da aplicação.

JavaScript: Funcionalidades e interatividade.
